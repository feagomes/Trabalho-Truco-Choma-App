# Trabalho Truco Choma

- UI em frontend/. API e regras do jogo em backend/.
- Use docs/api.md como contrato entre as duas partes. Mudanças de integração exigem atualizar o contrato.
- Considere a versão e a sessão da sala ao alterar o estado. O servidor valida as ações e entrega somente as cartas privadas da sessão solicitante.
- Use TTC-1 para mudanças de Front Web e TTC-2 para mudanças de Back.
